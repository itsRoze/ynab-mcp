# Security

Do not post credentials, OAuth callback URLs, real budget exports, or financial data in issues or pull requests.

Report vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/itsRoze/ynab-mcp/security/advisories/new). Include reproduction steps with synthetic data and the affected commit or version.

This is an early-stage, single-owner integration. Follow the latest main branch for fixes. Read the [deployment guide](docs/cloudflare.md#authentication-and-operating-notes) for credential rotation and OAuth grant revocation.
